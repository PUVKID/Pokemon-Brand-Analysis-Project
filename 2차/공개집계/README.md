# 📊 국가·플랫폼별 분류 집계

[분류별 건수](분류별_건수.csv)는 보존된 수집 결과의 국가·플랫폼·분류별 빈도입니다. 댓글·게시물 원문과 계정 정보는 포함하지 않습니다. 자동 코딩 결과이며 모집단을 대표하는 조사나 사람 검수의 일치도 결과로 해석하지 않습니다.

- `comments.csv`: 감성·행동 의도
- `hp_all.csv`: 홈페이지 목적·메시지 유형
- `sns_posts.csv`: SNS 목적·메시지 유형

[입력 템플릿](../)과 [수동 입력 양식](../manual/)을 이용해 같은 구조의 자료를 준비할 수 있습니다.
