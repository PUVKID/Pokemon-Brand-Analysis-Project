| 차수·위치 | 현재 파일 | 추가 경로 | 내용 변경 | 이전에만 존재 |
|---|---:|---:|---:|---:|
| `1차` | 1 | 1 | 0 | 0 |
| `2차` | 2 | 2 | 0 | 1 |

- 현재 연구 파일 합계: **3개**. 루트 `README.md`, `CHANGELOG.md`, `.gitignore`와 `docs/` 관리 문서는 집계에서 제외합니다.
- 경로에서 처음 만나는 숫자 차수 또는 `최종`으로 묶습니다. 같은 상위 경로의 숫자 차수끼리만 경로·SHA-256을 비교합니다. `기본`과 `최종`은 독립 묶음이므로 다른 차수와 자동으로 의미 대응시키지 않습니다.
- 추가·변경·이전 경로 수는 파일 비교 결과입니다. 기능 변경은 [README의 구체적인 구현·차수 설명](../README.md)을 함께 확인하세요.
- 제외된 원데이터·모델·인증정보와 관리 문서는 이 표의 대상이 아닙니다.

## ⚖️ 분석 방식 비교

| 항목 | 1차 리뷰 선행 실험 | 2차 포켓몬 콘텐츠 분석 |
|---|---|---|
| 입력 | 식품 브랜드 리뷰·별점 또는 수동 CSV | 한·중·일 채널 Excel·홈페이지·YouTube·수동 CSV |
| 처리 | 실제 별점 우선, 없으면 키워드 또는 선택한 API로 점수 추정 | 목적·메시지·감성·행동의도·토픽을 분류하고 수동값 우선 |
| 출력과 해석 | 추천·중립·비추천 비율과 소셜 지표; 0~10점 추천의향 설문은 아님 | CSV·Excel 사본·비교 그래프; 인기 댓글과 공식 채널 중심의 표본 |

[1차 노트북](../1차/brand_nps_auto_pipeline_v2.ipynb) · [2차 노트북](../2차/포켓몬30주년_올인원.ipynb) · [이전 Docker 사본](../2차/포켓몬30주년_올인원_이전도커버전.ipynb). 두 2차 사본의 확인된 코드 차이는 기본 파일의 선택적 `YOUTUBE_API_KEY`와 이전 사본의 필수 `GOOGLE_API_KEY`, 그리고 시작일 중복 선언입니다. 홈페이지 수집에는 시작일 필터가 적용되지 않습니다.
