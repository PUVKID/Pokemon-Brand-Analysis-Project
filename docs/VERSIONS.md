## 분석 방식 비교

**항목**

입력

**1차 리뷰 선행 실험**

식품 브랜드 리뷰·별점 또는 수동 CSV

**2차 포켓몬 콘텐츠 분석**

한·중·일 채널 Excel·홈페이지·YouTube·수동 CSV


**항목**

처리

**1차 리뷰 선행 실험**

실제 별점 우선, 없으면 키워드 또는 선택한 API로 점수 추정

**2차 포켓몬 콘텐츠 분석**

목적·메시지·감성·행동의도·토픽을 분류하고 수동값 우선


**항목**

출력과 해석

**1차 리뷰 선행 실험**

추천·중립·비추천 비율과 소셜 지표; 0~10점 추천의향 설문은 아님

**2차 포켓몬 콘텐츠 분석**

CSV·Excel 사본·비교 그래프; 인기 댓글과 공식 채널 중심의 표본



[1차 노트북](../1차/brand_nps_auto_pipeline_v2.ipynb) · [2차 노트북](../2차/포켓몬30주년_올인원.ipynb) · [이전 Docker 사본](../2차/포켓몬30주년_올인원_이전도커버전.ipynb). 두 2차 사본의 확인된 코드 차이는 기본 파일의 선택적 `YOUTUBE_API_KEY`와 이전 사본의 필수 `GOOGLE_API_KEY`, 그리고 시작일 중복 선언입니다. 홈페이지 수집에는 시작일 필터가 적용되지 않습니다.
