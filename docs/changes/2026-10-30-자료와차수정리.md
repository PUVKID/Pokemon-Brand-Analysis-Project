# 📝 자료와 차수별 기록 정리

[🏠 프로젝트](../../README.md) · [🗂️ 차수별 상세 안내](../REVISION_INDEX.md)

## ✨ 이번 정리

보존된 소스·실험 자료·문서를 차수별로 연결하고, 첫 화면에서 상세 설명과 파일별 비교를 볼 수 있게 정리했습니다. 논문이 있는 프로젝트는 현재 원고를 바로 읽을 수 있는 PDF와 편집 원본, 공식 논문 URL의 교체 위치를 구분합니다.

## 🔎 확인 범위

- 기존 원격 파일을 보존하고 새 자료·문서의 실제 바이트와 경로를 대조했습니다.
- 차수별 비교에는 주석·공백·문서 차이와 파일 크기·SHA-256을 포함합니다. 큰 바이너리 출력은 해시와 원문 링크로 구분합니다.
- 원고·소스·설명·링크와 형식을 검토했습니다. 이번 자료 정리가 새 학습·실험·제품 실행 결과를 뜻하지는 않습니다.
- 논문·문서는 공동저자 정보와 원문 서식을 보존합니다. 인증 비밀과 공개 권한이 구분되는 외부 자료는 별도로 관리합니다.
