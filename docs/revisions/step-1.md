### LEVEL 1·1차 식품 리뷰의 점수와 소셜 NPS

리뷰의 별점이 있으면 그 점수를 먼저 읽고 없을 때만 문장으로 점수를 추정합니다. 3점 안에는 실제 중립뿐 아니라 API 실패도 들어갈 수 있습니다. 추천 비율에서 비추천 비율을 뺀 값이 어떤 입력과 규칙에서 나왔는지 먼저 확인하세요.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-1-row-1"></a> 1차 입력과 점수 우선순위 | 선행 실험의 입력은 식품 브랜드 리뷰입니다.<br>실제 별점이 있으면 우선 쓰고 없으면 키워드 또는 선택 Gemini API로 1~5점을 추정합니다. 2차 포켓몬 콘텐츠와 다른 대상입니다. |
| <a id="layout18-table-1-row-2"></a> 키워드 함수의 구간 | 가중치 합계 ≥5 →5점,2~4 →4점,-1~1 →3점,-4~-2 →2점, 그 밖 →1점입니다.<br>앞의 이전 설명 표와 달라 실제 함수를 기준으로 읽습니다.<br>처음 찾은 위치 중심 가중치·간단한 부정 어 규칙이며 모든 반복 횟수를 세는 방식은 아닙니다. |
| <a id="layout18-table-1-row-3"></a> 추천·중립·비추천 집계 | 4~5점은 추천,3점은 중립,1~2점은 비추천입니다.<br>반올림한 추천 비율과 비 추천 비율의 차를 계산합니다. 0~10점 추천 의향 설문을 직접 받아 계산한 정식 NPS와 측정 방법이 다릅니다. |
| <a id="layout18-table-1-row-4"></a> 선택 LLM 경로 | google-genai·GOOGLE_API_KEY가 필요하고 모든 리뷰 본문을 외부 API에 보냅니다.<br>재시도·배치 분할 후에도 실패하면 3점을 넣으므로 실패 대체 값이 실제 중립 반응에 섞입니다.<br>로그에서 실패 건수를 구분해야 합니다. |

실제 별점 우선·키워드 구간·LLM 실패 3점·비율 반올림 후 차를 계산하는 구현을 측정 정의로 고정합니다. 설문형 NPS와 동치로 간주할 수 없고 중립 비율에는 실패 대체가 섞일 수 있으므로 원 로그·분모·점수 출처를 함께 검토합니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-21-row-1"></a> 1차 입력과 점수 우선순위 | 선행 실험의 입력은 식품 브랜드 리뷰입니다.<br>실제 별점이 있으면 우선 쓰고 없으면 키워드 또는 선택 Gemini API로 1~5점을 추정합니다. 2차 포켓몬 콘텐츠와 다른 대상입니다. |
| <a id="layout18-table-21-row-2"></a> 키워드 함수의 구간 | 가중치 합계 ≥5 →5점,2~4 →4점,-1~1 →3점,-4~-2 →2점, 그 밖 →1점입니다.<br>앞의 이전 설명 표와 달라 실제 함수를 기준으로 읽습니다.<br>처음 찾은 위치 중심 가중치·간단한 부정 어 규칙이며 모든 반복 횟수를 세는 방식은 아닙니다. |
| <a id="layout18-table-21-row-3"></a> 추천·중립·비추천 집계 | 4~5점은 추천,3점은 중립,1~2점은 비추천입니다.<br>반올림한 추천 비율과 비 추천 비율의 차를 계산합니다. 0~10점 추천 의향 설문을 직접 받아 계산한 정식 NPS와 측정 방법이 다릅니다. |
| <a id="layout18-table-21-row-4"></a> 선택 LLM 경로 | google-genai·GOOGLE_API_KEY가 필요하고 모든 리뷰 본문을 외부 API에 보냅니다.<br>재시도·배치 분할 후에도 실패하면 3점을 넣으므로 실패 대체 값이 실제 중립 반응에 섞입니다.<br>로그에서 실패 건수를 구분해야 합니다. |

<a name="usage"></a>

## 실행 순서

1. 노트북에서 수집 대상 URL·페이지 구조와 입력 파일 위치를 확인합니다.
2. 별점 우선 경로와 텍스트 추정 경로 중 사용할 방식을 정합니다.
3. 키워드 사전·부정어 처리와 점수 구간을 확인하고 필요한 셀을 순서대로 읽습니다.
4. 추천·중립·비추천의 분모와 수집·분류 실패 건수를 확인한 뒤 집계 결과를 해석합니다.

<a name="results"></a>

<a id="-결과를-읽는-방법"></a>

## 결과와 해석

키워드 함수의 점수 구간은 노트북 앞부분의 이전 설명표와 다른 부분이 있어 실제 함수 기준으로 읽어야 합니다. 반복 키워드 전체 횟수가 아니라 처음 찾은 위치를 중심으로 가중치를 적용합니다.

LLM 경로는 리뷰 본문을 외부 API로 보내며, 재시도·배치 분할 후에도 실패한 건은 3점으로 처리합니다. 이 대체 값이 중립 반응에 섞이는 점과 반올림 한 비율 차로 지표를 계산하는 방식을 함께 확인합니다.
