### LEVEL 1 · 처리 절차

1. 입력 Excel6개와 DATA_DIR·시트 구조를 확인합니다.
2. 수집 기간·공식 채널 링크와 API를 사용할 범위를 정하고 미지원 자료는 수동 CSV에 준비합니다.
3. 수집→분류→시트 사본 작성→분석 구간을 나누어 읽고 필요한 단계만 실행합니다.
4. human 열을 사람이 채운 표본을 별도로 보관한 뒤 κ·일치율의 유효쌍 수를 확인합니다.
5. 기존 결과를 다시 볼 때는 data CSV와 결과 Excel·그래프를 먼저 열어 새 수집과 구분합니다.

저장된 자료와 결과를 먼저 보고 필요한 노트북을 고릅니다. API 경로를 실행하면 글이 외부로 전송될 수 있습니다. 표를 읽는 것과 새로운 수집·분류를 실행하는 것은 다릅니다.

### LEVEL 1 · 결과를 확인하는 방법

보관된 data와 검수 표본 파일의 행 수입니다.

| 자료 | 보관된 data | 검수 표본 파일 |
| --- | ---: | ---: |
| 댓글 | 5585행 | 100행 |
| 게시물 | 400행 | 28행 |
| 홈페이지 | 73행 | 35행 |

### LEVEL 2 · 처리 절차

1. 입력 Excel6개와 DATA_DIR·시트 구조를 확인합니다.
2. 수집 기간·공식 채널 링크와 API를 사용할 범위를 정하고 미지원 자료는 수동 CSV에 준비합니다.
3. 수집→분류→시트 사본 작성→분석 구간을 나누어 읽고 필요한 단계만 실행합니다.
4. human 열을 사람이 채운 표본을 별도로 보관한 뒤 κ·일치율의 유효쌍 수를 확인합니다.
5. 기존 결과를 다시 볼 때는 data CSV와 결과 Excel·그래프를 먼저 열어 새 수집과 구분합니다.

1차·2차 상세의 실행 순서를 따르고 인증 환경변수와 입력 경로를 확인합니다. 이전 Docker 사본은 현재 기본 파일과 선언 차이가 있습니다. 파일이 보인다는 사실만으로 완성된 실행 환경이 제공된다고 판단하지 않습니다.

### LEVEL 2 · 결과를 확인하는 방법

보관된 data와 검수 표본 파일의 행 수입니다.

| 자료 | 보관된 data | 검수 표본 파일 |
| --- | ---: | ---: |
| 댓글 | 5585행 | 100행 |
| 게시물 | 400행 | 28행 |
| 홈페이지 | 73행 | 35행 |

검수 표본 파일의 행 수는 사람이 검수를 모두 마친 건수와 같은 뜻이 아닙니다.

참여율은(좋아요+댓글+공유)/조회수×100이고 YouTube 공유수는 제공되지 않는 값을 0으로 기록합니다. Wilson 구간·카이제곱/Cramér V·Kruskal–Wallis/ε²·Mann–Whitney/Bonferroni·Spearman 결과는 표본과 유효 건수를 함께 읽습니다.

저장 행 수는 수집물의 크기, 검수 표본 행 수는 검토 대상으로 뽑힌 크기입니다. 두 분모를 나누어 읽습니다. 인기순 댓글과 공식 채널의 반응을 국가 전체 소비자의 평가로 해석하지 않습니다.

2차 기본 파일과 이전 Docker 사본은 인증 환경변수와 시작일 중복 선언의 차이를 구분합니다.

### LEVEL 3 · 처리 절차

1. 입력 Excel6개와 DATA_DIR·시트 구조를 확인합니다.
2. 수집 기간·공식 채널 링크와 API를 사용할 범위를 정하고 미지원 자료는 수동 CSV에 준비합니다.
3. 수집→분류→시트 사본 작성→분석 구간을 나누어 읽고 필요한 단계만 실행합니다.
4. human 열을 사람이 채운 표본을 별도로 보관한 뒤 κ·일치율의 유효쌍 수를 확인합니다.
5. 기존 결과를 다시 볼 때는 data CSV와 결과 Excel·그래프를 먼저 열어 새 수집과 구분합니다.

수집 기간·대상 채널·정렬 기준을 확인하고 기존 결과와 새 실행을 분리합니다. 2차 기본 파일과 이전 Docker 사본의 인증 환경변수·시작일 중복 선언 차이를 대조합니다. 표본 파일의 행 수를 검수 완료 수로 쓰지 않습니다.

### LEVEL 3 · 결과를 확인하는 방법

보관된 data와 검수 표본 파일의 행 수입니다.

| 자료 | 보관된 data | 검수 표본 파일 |
| --- | ---: | ---: |
| 댓글 | 5585행 | 100행 |
| 게시물 | 400행 | 28행 |
| 홈페이지 | 73행 | 35행 |

검수 표본 파일의 행 수는 사람이 검수를 모두 마친 건수와 같은 뜻이 아닙니다.

참여율은(좋아요+댓글+공유)/조회수×100이고 YouTube 공유수는 제공되지 않는 값을 0으로 기록합니다. Wilson 구간·카이제곱/Cramér V·Kruskal–Wallis/ε²·Mann–Whitney/Bonferroni·Spearman 결과는 표본과 유효 건수를 함께 읽습니다.

표에서 원자료와 검수 표본 열을 각각 확인합니다. 5585/400/73행과 100/28/35행의 대응을 유지하고 검수 완료 여부는 별도 근거로 봅니다. 그래프의 비율만으로 자료 범위가 같다고 판단하지 않습니다.

<a id="-준비와-사용-순서"></a>

## 실행 순서

1. 입력 Excel6개와 DATA_DIR·시트 구조를 확인합니다.
2. 수집 기간·공식 채널 링크와 API를 사용할 범위를 정하고 미지원 자료는 수동 CSV에 준비합니다.
3. 수집→분류→시트 사본 작성→분석 구간을 나누어 읽고 필요한 단계만 실행합니다.
4. human 열을 사람이 채운 표본을 별도로 보관한 뒤 κ·일치율의 유효쌍 수를 확인합니다.
5. 기존 결과를 다시 볼 때는 data CSV와 결과 Excel·그래프를 먼저 열어 새 수집과 구분합니다.

<a id="-결과를-읽는-방법"></a>

## 결과와 해석

보관된 data와 검수 표본 파일의 행 수입니다.

| 자료 | 보관된 data | 검수 표본 파일 |
| --- | ---: | ---: |
| 댓글 | 5585행 | 100행 |
| 게시물 | 400행 | 28행 |
| 홈페이지 | 73행 | 35행 |

검수 표본 파일의 행 수는 사람이 검수를 모두 마친 건수와 같은 뜻이 아닙니다.

참여율은(좋아요+댓글+공유)/조회수×100이고 YouTube 공유수는 제공되지 않는 값을 0으로 기록합니다. Wilson 구간·카이제곱/Cramér V·Kruskal–Wallis/ε²·Mann–Whitney/Bonferroni·Spearman 결과는 표본과 유효 건수를 함께 읽습니다.
