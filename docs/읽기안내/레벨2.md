## 문제와 주요 기능

1차 소셜 NPS는 감성 점수를 추천·중립·비추천으로 묶어 비율 차이를 계산합니다. 2차는 국가별 채널 콘텐츠의 주제를 분류합니다. 점수의 의미와 분석 목적이 달라지는 점을 먼저 봅니다.

<a id="guide-flow"></a>

## 입력·처리·출력

1차는 수집 →1~5점 추정 →추천 범주 →비율 차이입니다. 2차는 채널별 수집 →정규화 →콘텐츠 분류 →검수 표본·비교표입니다. 원문과 분류 값, 집계 단위를 연결해 읽습니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

1차·2차 상세의 실행 순서를 따르고 인증 환경 변수와 입력 경로를 확인합니다. 이전 Docker 사본은 현재 기본 파일과 선언 차이가 있습니다. 파일이 보인다는 사실만으로 완성된 실행 환경이 제공된다고 판단하지 않습니다.

<a id="guide-results"></a>

## 관측 결과와 해석

저장 행 수는 수집물의 크기, 검수 표본 행 수는 검토 대상으로 뽑힌 크기입니다. 두 분모를 나누어 읽습니다. 인기순 댓글과 공식 채널의 반응을 국가 전체 소비자의 평가로 해석하지 않습니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

### LEVEL 2 · 비율·검정·관계 분석을 구분하기

참여율을 만든 뒤 범주·분포·상관이라는 질문에 맞게 분석 도구가 나뉩니다. Wilson은 비율 추정,Cramér’s V/ε² 는 효과 크기,Bonferroni 는 비교를 여러 번 한 문제를 다룹니다. 이 도구들은 서로 대체하는 점수가 아닙니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-5-row-1"></a> 참여율 | (좋아요 +댓글 +공유)/조회 수 ×100입니다.<br>조회 수 0·결 측은 제외합니다.<br>YouTube는 공유 수를 제공하지 않아 0으로 기록하므로 실제 공유가 0이었다는 관측과 다릅니다. |
| <a id="layout18-table-5-row-2"></a> 행동 의도와 범주 비교 | 95% Wilson 구간은 국가별 비율의 불확실성을 봅니다.<br>카이제곱은 범주 구성 차이,Cramér’s V는 그 관련 크기를 봅니다.<br>작은 기대 빈도 경고가 있으면 검정 해석을 함께 점검해야 합니다. |
| <a id="layout18-table-5-row-3"></a> 분포와 국가 쌍 비교 | Kruskal–Wallis·ε² 는 국가 간 분포 비교와 효과 크기,Mann–Whitney U는 국가 쌍 비교,Bonferroni는 여러 비교를 한 데 따른 보정입니다. |
| <a id="layout18-table-5-row-4"></a> 상관과 산출물 | Spearman은 게시물 참여율과 댓글 평균 감성의 관계를 살핍니다.<br>표 3개·PNG 그래프 10개가 현황·지표·검정 결과를 보여 줍니다.<br>관계가 있다는 사실이 캠페인의 인과 효과를 증명하지는 않습니다. |


<a id="semantic-human-level-2"></a>

### LEVEL 2 · 사람 검수와 저장 결과의 의미

수집 자료 →자동 범주 →검수표본 →사람 라벨 →κ/일치율의 순서입니다. 5585개 댓글이 있다고 모두 사람이 확인한 것은 아닙니다. 검수 지표는 입력 규모보다 실제 서로 비교 가능한 라벨쌍에 의해 결정됩니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-6-row-1"></a> 보관 자료와 표본 | 댓글 data5585 행/검수 표본 100 행, 게시 물400/28, 홈페이지73/35입니다.<br>표본 파일 행 수는 사람이 검수 완료한 건수가 아닙니다. |
| <a id="layout18-table-6-row-2"></a> 표본 상한과 human _* | 국가별 댓글 최대 50개, 게시물·홈페이지 각각 최대 14개를 뽑습니다.<br>후자 두 자료는 각각 3개국 최대 42개이며 확보 량에 따라 줄어듭니다.<br>사람이 human _*열을 채운 뒤 검수 지표를 계산합니다. |
| <a id="layout18-table-6-row-3"></a> Cohen’s κ와 일치율 | κ는 우연 일치를 고려한 분류 일치 지표입니다.일부만 채운 파일에서는 κ의 유효쌍과 일치율 분모가 달라질 수 있으므로 실제 채운 표본과 분모를 확인합니다. |
| <a id="layout18-table-6-row-4"></a> 폴더별 자료 역할 | data/는 수집 CSV·검수표본, 수집 결과/는 국가별 Excel 사본, 결과/분석 결과 _통합.xlsx는 통합 분석, 결과/figures/는 10 그래프,manual/은 수동 입력입니다.<br>자동 분류와 사람 정답을 구분해 읽습니다. |


<a id="semantic-limitations-level-2"></a>

### LEVEL 2 · 재실행·수집 실패와 해석의 한계

기간 필터·인기 정렬·접근 실패·URL 변환은 모두 모이는 자료에 영향을 줍니다. 한 단계의 누락이 뒤의 국가 비교로 이어질 수 있습니다. 표와 그래프는 확보된 표본의 분석이며 전체 여론이나 인과 효과를 설명하지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-7-row-1"></a> 대표성과 기간 | 공식 채널·인기 순 댓글 중심의 비확률 표본입니다.<br>국가 전체 소비자를 대표하지 않습니다.<br>홈페이지에는 SNS와 같은 기간 필터가 적용되지 않습니다. |
| <a id="layout18-table-7-row-2"></a> 접근 과 정규화 | robots.txt 조회 실패는 허용으로 처리됩니다.<br>URL 정규화는 대소 문자를 바꾸므로 대소 문자를 구분하는 게시물 ID의 링크가 맞는지 확인해야 합니다. |
| <a id="layout18-table-7-row-3"></a> 재작성되는 파일 | 원본 Excel 사본을 사용하지만 같은 이름 출력 Excel·CSV·검수표본은 재실행 시 다시 씁니다.<br>사람이 채운 검수 파일은 먼저 별도 보존합니다. |
| <a id="layout18-table-7-row-4"></a> 증상별 확인 점 | Excel 오류는 DATA_DIR·파일/시트,YouTube 실패는 키·서비스 설정·쿼터, 빈 웹 수집은 페이지 구조·JS·접근 조건을 확인합니다.<br>미지원 채널은 manual CSV, 감성 차이는 모델/사전/사람 표본, 한글 오류는 폰트 설정을 봅니다. |
