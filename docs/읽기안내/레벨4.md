## 프로젝트 소개

수집·정규화·분류·통계·보고의 경계가 분석의 재현성을 좌우합니다. 인기순·공식 채널 중심의 비확률 표본과 실패 시 점수 대체가 집계에 영향을 줍니다. 다국가 비교는 표본 설계가 같은지부터 검토해야 합니다.


<a id="guide-problem"></a>

## 문제와 주요 기능

| 대상·조건 | 동작과 의미 |
| --- | --- |
| 선택 Gemini 요청 | 키워드와 선택적 Gemini API는 서로 다른 측정 경로입니다. |
| API 요청·실패 | API 실패 후 3점 대체는 결측을 제거하는 처리와 다릅니다. |
| 실패·미검증 | 분류기 선택·실패 정책·비율 반올림이 최종 소셜 NPS에 어떻게 들어가는지 추적합니다. |

### LEVEL 4·1차 식품 리뷰의 점수와 소셜 NPS

첫 발견 위치 기반 가중치는 반복 빈도 분석과 다르며 부정어 규칙은 제한적입니다.

점수 변환 경로가 다른 자료를 같은 추천/비추천으로 압축할 때 측정 오차가 전파됩니다.

반올림한 비율을 먼저 뺀다는 계산 순서도 보존해야 합니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-3-row-1"></a> 1차 입력과 점수 우선순위 | 선행 실험의 입력은 식품 브랜드 리뷰입니다.<br>실제 별점이 있으면 우선 쓰고 없으면 키워드 또는 선택 Gemini API로 1~5점을 추정합니다. 2차 포켓몬 콘텐츠와 다른 대상입니다. |
| <a id="layout18-table-3-row-2"></a> 키워드 함수의 구간 | 가중치 합계 ≥5 →5점,2~4 →4점,-1~1 →3점,-4~-2 →2점, 그 밖 →1점입니다.<br>앞의 이전 설명 표와 달라 실제 함수를 기준으로 읽습니다.<br>처음 찾은 위치 중심 가중치·간단한 부정 어 규칙이며 모든 반복 횟수를 세는 방식은 아닙니다. |
| <a id="layout18-table-3-row-3"></a> 추천·중립·비추천 집계 | 4~5점은 추천,3점은 중립,1~2점은 비추천입니다.<br>반올림한 추천 비율과 비 추천 비율의 차를 계산합니다. 0~10점 추천 의향 설문을 직접 받아 계산한 정식 NPS와 측정 방법이 다릅니다. |
| <a id="layout18-table-3-row-4"></a> 선택 LLM 경로 | google-genai·GOOGLE_API_KEY가 필요하고 모든 리뷰 본문을 외부 API에 보냅니다.<br>재시도·배치 분할 후에도 실패하면 3점을 넣으므로 실패 대체 값이 실제 중립 반응에 섞입니다.<br>로그에서 실패 건수를 구분해야 합니다. |

### LEVEL 4·2차수집과 자동 분류의 준비

페이지 구조/JS 렌더링과 API 쿼터가 수집 범위를, 감성 모델 로드 실패와 수동 값 우선 이 분류 경로를 바꿉니다.

END_DATE =None은 재실행 시점에 따라 입력 표본이 달라지는 설정입니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> 준비와 실행 순서 | 2차는 한국·중국·일본 홈페이지/SNS/댓글을 비교합니다.<br>원본 Excel6개와 DATA_DIR, 채널 링크·기간을 확인하고 수집 →분류 →표 작성 →분석 순서로 진행합니다.<br>미지원 자료는 manual/CSV로 넣습니다. |
| <a id="layout18-table-4-row-2"></a> 도구 역할 | requests는 문서 요청,BeautifulSoup은 페이지에서 내용 추출,pandas는 표 처리,openpyxl은 Excel,Matplotlib은 그래프를 맡습니다.<br>선택 yt-dlp·감성 모델·Playwright는 실행 경로에 따라 필요하며 사람 검 수의 정답을 대신하지 않습니다. |
| <a id="layout18-table-4-row-3"></a> 기간·표본 상한 | 기본 국가 순서는 한국·중국·일본, 시작2026-01-01, 종료 None은 실행 당시 날짜입니다.<br>채널당 영상 최대 100, 영상 당 댓글 최대 30,relevance 정렬이 수집 표본을 제한합니다. |
| <a id="layout18-table-4-row-4"></a> 분류 값 | 캠페인 목적 3 종·제안 4 종·내부자형/초대형·감성-1/0/1·행동 의도 O/X·토픽을 정리합니다.<br>선택 감성 모델이 로드 실패하면 사전 방식으로 바꾸고 유효한 수동 CSV 분류 값이 있으면 우선합니다. |
| <a id="layout18-table-4-row-5"></a> 인증·실행 사본 차이 | 기본 2차는 YOUTUBE_API_KEY가 없으면 YouTube 수집을 건너뜁니다.<br>이전 Docker 이름 사본은 GOOGLE_API_KEY가 없으면 KeyError로 중단합니다.<br>Docker 이름이 컨테이너 환경 포함을 뜻하지 않습니다.pip/apt 설치·폰트 셀도 실행 전에 확인합니다. |

### LEVEL 4 · 비율·검정·관계 분석을 구분하기

분모 결 측 처리와 플랫폼별 누락 값의 0 기록은 참여율 비교에 영향을 줍니다.

범주/순위 분포/상관은 다른 분석 단위이므로 동일한 효과로 합치지 않습니다.

여러 국가 쌍 검 정의 보정과 작은 기대 빈도 경고를 유지해야 합니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-5-row-1"></a> 참여율 | (좋아요 +댓글 +공유)/조회 수 ×100입니다.<br>조회 수 0·결 측은 제외합니다.<br>YouTube는 공유 수를 제공하지 않아 0으로 기록하므로 실제 공유가 0이었다는 관측과 다릅니다. |
| <a id="layout18-table-5-row-2"></a> 행동 의도와 범주 비교 | 95% Wilson 구간은 국가별 비율의 불확실성을 봅니다.<br>카이제곱은 범주 구성 차이,Cramér’s V는 그 관련 크기를 봅니다.<br>작은 기대 빈도 경고가 있으면 검정 해석을 함께 점검해야 합니다. |
| <a id="layout18-table-5-row-3"></a> 분포와 국가 쌍 비교 | Kruskal–Wallis·ε² 는 국가 간 분포 비교와 효과 크기,Mann–Whitney U는 국가 쌍 비교,Bonferroni는 여러 비교를 한 데 따른 보정입니다. |
| <a id="layout18-table-5-row-4"></a> 상관과 산출물 | Spearman은 게시물 참여율과 댓글 평균 감성의 관계를 살핍니다.<br>표 3개·PNG 그래프 10개가 현황·지표·검정 결과를 보여 줍니다.<br>관계가 있다는 사실이 캠페인의 인과 효과를 증명하지는 않습니다. |

<a id="semantic-human-level-4"></a>

### LEVEL 4 · 사람 검수와 저장 결과의 의미

라벨 출처와 결측 처리 경계가 핵심입니다.

자동 분류 출력과 수동정답을 섞으면 검수 의미가 달라집니다.

부분 검수일 때 서로 다른 유효쌍/분모를 사용하는 지표는 같은 표본의 점수라고 단순 비교할 수 없습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-6-row-1"></a> 보관 자료와 표본 | 댓글 data5585 행/검수 표본 100 행, 게시 물400/28, 홈페이지73/35입니다.<br>표본 파일 행 수는 사람이 검수 완료한 건수가 아닙니다. |
| <a id="layout18-table-6-row-2"></a> 표본 상한과 human _* | 국가별 댓글 최대 50개, 게시물·홈페이지 각각 최대 14개를 뽑습니다.<br>후자 두 자료는 각각 3개국 최대 42개이며 확보 량에 따라 줄어듭니다.<br>사람이 human _*열을 채운 뒤 검수 지표를 계산합니다. |
| <a id="layout18-table-6-row-3"></a> Cohen’s κ와 일치율 | κ는 우연 일치를 고려한 분류 일치 지표입니다.일부만 채운 파일에서는 κ의 유효쌍과 일치율 분모가 달라질 수 있으므로 실제 채운 표본과 분모를 확인합니다. |
| <a id="layout18-table-6-row-4"></a> 폴더별 자료 역할 | data/는 수집 CSV·검수표본, 수집 결과/는 국가별 Excel 사본, 결과/분석 결과 _통합.xlsx는 통합 분석, 결과/figures/는 10 그래프,manual/은 수동 입력입니다.<br>자동 분류와 사람 정답을 구분해 읽습니다. |

<a id="semantic-limitations-level-4"></a>

### LEVEL 4 · 재실행·수집 실패와 해석의 한계

수집 단계의 조건 차이를 분석 단계에서 자동 보정한 것으로 취급할 수 없습니다.

홈페이지와 SNS의 기간 차이, 실패 허용 robots 정책, 식별자 소문자화는 별도 검토 대상입니다.

고정 출력 명은 사람 검수 이력을 손실시킬 수 있습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-7-row-1"></a> 대표성과 기간 | 공식 채널·인기 순 댓글 중심의 비확률 표본입니다.<br>국가 전체 소비자를 대표하지 않습니다.<br>홈페이지에는 SNS와 같은 기간 필터가 적용되지 않습니다. |
| <a id="layout18-table-7-row-2"></a> 접근 과 정규화 | robots.txt 조회 실패는 허용으로 처리됩니다.<br>URL 정규화는 대소 문자를 바꾸므로 대소 문자를 구분하는 게시물 ID의 링크가 맞는지 확인해야 합니다. |
| <a id="layout18-table-7-row-3"></a> 재작성되는 파일 | 원본 Excel 사본을 사용하지만 같은 이름 출력 Excel·CSV·검수표본은 재실행 시 다시 씁니다.<br>사람이 채운 검수 파일은 먼저 별도 보존합니다. |
| <a id="layout18-table-7-row-4"></a> 증상별 확인 점 | Excel 오류는 DATA_DIR·파일/시트,YouTube 실패는 키·서비스 설정·쿼터, 빈 웹 수집은 페이지 구조·JS·접근 조건을 확인합니다.<br>미지원 채널은 manual CSV, 감성 차이는 모델/사전/사람 표본, 한글 오류는 폰트 설정을 봅니다. |
